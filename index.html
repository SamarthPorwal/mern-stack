How the four parts talk to each other

React runs in the browser. Express runs on Node.js on the server. MongoDB keeps the data. They pass messages in JSON, so everything speaks JavaScript.

Questions

Common questions

Do I need to know coding before I start?

No. You start from HTML and CSS, then learn JavaScript step by step. If you can use a computer and are ready to practise, you can learn this.

Why learn MERN and not something else?

MERN uses one language, JavaScript, for everything. You learn it once and use it on the screen, on the server and with the database. React, Node.js and MongoDB are also very widely used by companies.

What is the difference between React and JavaScript?

JavaScript is the language. React is a library written in JavaScript that makes it much easier to build big, fast user interfaces from small reusable pieces.

What is the difference between Node.js and Express?

Node.js lets JavaScript run on a server. Express is a small framework on top of Node.js that makes it easy to create routes and APIs.

Do I need a powerful laptop?

No. A normal laptop with a browser, VS Code and Node.js installed is enough. The database can run free in the cloud on MongoDB Atlas.

Will I put my work online?

Yes. You will learn to push code to GitHub and deploy apps so anyone can open them with a link. This becomes your portfolio.
